# 1. Project Name
HandTogether
# 2. Short Description
HandTogether is a modern, responsive, and community-driven volunteer mobilization and social service platform designed for Bangladesh. The platform bridges the gap between passionate volunteers and local grassroots organizers, empowering communities to plan, discover, and execute vital humanitarian initiatives. From winter warmth and blanket distribution drives to emergency food aid, free medical camps, cleanliness drives, and tree plantations—HandTogether provides a transparent, zero-bureaucracy ecosystem. With real-time volunteer rostering, verified coordinator contacts, and seamless event management, the platform transforms collective goodwill into immediate, measurable social impact.

# 3. Technologies Used
- **Next.js 16 (App Router)**
- **React 19 & TypeScript**
- **Tailwind CSS**
- **Node.js & Express.js**
- **MongoDB & MongoDB Atlas**
- **SweetAlert2 & React Hot Toast**
- **Lucide React Icons**

# 4. 5 Key Features of HandTogether

 1. Dynamic Community Drives & Smart Category Filtering
 2. Comprehensive Event Details & Real-Time Volunteer Rostering
 3. Protected Event Creation & Ownership Binding
 4. Organizer Dashboard with Strict Role-Based Permissions (CRUD)
 5. Events update or delete from mongo db
